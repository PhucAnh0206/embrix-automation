# 📊 Revenue Recognition

> **Parent**: [[00-MOC-Embrix-Knowledge-Base]] | **Hub**: Revenue
> **Related**: [[50-REV-GL-Posting]] | [[30-BILL-Billing-Cycle]]

---

## 1. Recognition Rules

| Rule | Description |
|------|-------------|
| **Recurring Revenue** | Recognized monthly over the service period |
| **One-Time Revenue** | Recognized at point of delivery |
| **Usage Revenue** | Recognized when usage occurs |
| **Deferred Revenue** | Advance billing → recognized over time |

## 2. ASC 606 / IFRS 15 Compliance

| Step | Description |
|------|-------------|
| 1 | Identify the contract |
| 2 | Identify performance obligations |
| 3 | Determine transaction price |
| 4 | Allocate price to obligations |
| 5 | Recognize revenue as obligations are satisfied |

## 3. Deferred Revenue Handling

```
Advance Billing (Jan 1 for Jan service):
  Jan 1: DR AR $30 / CR Deferred Revenue $30
  Jan 31: DR Deferred Revenue $30 / CR Revenue $30
```
