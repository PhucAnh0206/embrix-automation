# 📊 Selling Company

> **Parent**: [[00-MOC-Embrix-Knowledge-Base]] | **Hub**: Revenue
> **Related**: [[50-REV-GL-Posting]] | [[10-CUST-Account-Management]]

---

## 1. Concept

A Selling Company represents a **business unit or legal entity** that sells services. Multi-tenant operators may have multiple selling companies.

## 2. Configuration

| Field | Description | Example |
|-------|-------------|---------|
| **Code** | Unique identifier | 0900 |
| **Name** | Company name | Coopeguanacaste Telecom |
| **Tax ID** | Tax registration number | 3-004-045118 |
| **Address** | Registered address | Guanacaste, CR |
| **Currency** | Default currency | CRC |
| **GL Prefix** | GL account prefix | 0900- |

## 3. Usage

- Appears on invoices as the billing entity
- Determines GL posting prefix
- Controls tax configuration
- May have different pricing catalogs
