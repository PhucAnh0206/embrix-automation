# 📚 Glossary

> **Parent**: [[00-MOC-Embrix-Knowledge-Base]] | **Hub**: Reference

---

## Terms

| Term | Definition |
|------|------------|
| **ARPU** | Average Revenue Per User. A measure of the revenue generated per subscriber. |
| **BDOM** | Billing Day of Month. The day of the month on which an account's billing cycle begins. |
| **BSS** | Business Support Systems. Systems that deal with the business side of a telecom network (billing, CRM, etc.). |
| **CDR** | Call Detail Record. A record containing details of a phone call or data session. |
| **Dunning** | The process of communicating with customers to ensure the collection of accounts receivable. |
| **GL** | General Ledger. The main accounting record of a business. |
| **HLR** | Home Location Register. A database used in mobile networks containing subscriber details. |
| **MRR** | Monthly Recurring Revenue. The predictable revenue generated by subscribers every month. |
| **OSS** | Operations Support Systems. Systems that deal with the operational side of a telecom network (provisioning, network management). |
| **Proration** | The proportional distribution of charges based on time, usually when a service is active for only part of a billing cycle. |
| **Provisioning** | The process of preparing and equipping a network to allow it to provide new services to users. |
| **Rating** | The process of calculating the cost of a usage event (like a call or data session) based on CDR data. |
