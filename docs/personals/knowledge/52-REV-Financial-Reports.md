# 📊 Financial Reports

> **Parent**: [[00-MOC-Embrix-Knowledge-Base]] | **Hub**: Revenue
> **Related**: [[50-REV-GL-Posting]] | [[51-REV-Revenue-Recognition]]

---

## 1. Available Reports

| Report | Description |
|--------|-------------|
| **Revenue Summary** | Total revenue by period, product line |
| **AR Aging** | Outstanding balances by aging bucket |
| **Invoice Register** | List of all invoices generated |
| **Payment Register** | List of all payments received |
| **GL Journal** | All journal entries posted |
| **Tax Report** | Tax collected and payable |
| **Deferred Revenue** | Unearned revenue balances |

## 2. Report Parameters

| Parameter | Options |
|-----------|---------|
| **Date Range** | From/To dates |
| **Account** | Specific or all accounts |
| **Product Line** | Filter by product category |
| **Format** | Screen, CSV, PDF |

## 3. UI Path

```
Revenue Center → Reports → Select Report Type →
  Set Parameters → GENERATE → View/Export
```
