# ⚙️ Dashboard & KPIs

> **Parent**: [[00-MOC-Embrix-Knowledge-Base]] | **Hub**: Operations
> **Related**: [[52-REV-Financial-Reports]] | [[43-AR-Aging-Report]]

---

## 1. Executive Dashboard

| Widget | Metric |
|--------|--------|
| **MRR** | Monthly Recurring Revenue |
| **ARPU** | Average Revenue Per User |
| **Churn Rate** | % subscribers lost per month |
| **Collection Rate** | % of invoiced amount collected |
| **AR Aging** | Outstanding by bucket |
| **Active Subs** | Total active subscriptions |

## 2. Operational Dashboard

| Widget | Metric |
|--------|--------|
| **Job Status** | Running / Completed / Failed jobs |
| **CDR Processing** | Ingested / Rated / Error CDRs |
| **Provisioning** | Pending / Completed / Failed orders |
| **System Health** | CPU, Memory, API response time |

## 3. Custom Reports

Users can build custom reports via:
- Date range filters
- Grouping by account, product, region
- Export to CSV/PDF
- Schedule for recurring email delivery
